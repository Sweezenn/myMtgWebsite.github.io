Utiliser MTG Cube Sorter

Le Card Sorter permet d'annoter les cartes du cube selon plusieurs criteres, de reprendre son travail plus tard et de partager une session complete.

1. Demarrer

  1. Ouvrez Card Sorter.
  2. Les cartes du cube sont chargees automatiquement par defaut.
  3. Si une session precedente existe, elle est restauree automatiquement.
  4. Cliquez sur une carte pour ouvrir son detail.
Important : le travail reste dans le navigateur. Il n'y a pas de compte ni de serveur necessaire.

2. Galerie et filtres

La galerie affiche toutes les cartes dans l'ordre numerique du cube. Utilisez la barre de recherche pour retrouver une carte par son nom.

Taille des cartes

Le menu Taille propose trois densites : Petites pour parcourir rapidement, Moyennes pour l'usage courant et Grandes pour mieux lire les illustrations.

Filtres

Les boutons Toutes et Non triees filtrent l'etat general. Les menus par dimension permettent de retrouver, par exemple, toutes les cartes avec un Color Pie non respecte.

Le bouton Trier ouvre directement la prochaine carte qui n'est pas complete.

3. Trier une carte

Dans le detail, chaque dimension apparait dans un bloc. Cliquez sur une reponse pour la selectionner. Les couleurs indiquent l'etat :

  • Vert : reponse positive ou carte evaluee.
  • Rouge : reponse negative.
  • Neutre : dimension encore non selectionnee.

Les dimensions marquees REQUIS doivent etre completees pour qu'une carte soit consideree comme triee. Cliquez sur le titre d'une dimension pour replier son contenu.

Ajoutez un commentaire dans la zone Notes. Les boutons Precedent, Suivant et Galerie permettent de naviguer sans perdre le contexte.

4. Sur mobile

  • La barre des filtres est repliee par defaut : ouvrez-la avec Filtres.
  • Glissez vers la gauche pour passer a la carte suivante.
  • Glissez vers la droite pour revenir a la carte precedente.
  • Les mouvements verticaux servent a faire defiler les dimensions et les notes.
  • Les raccourcis clavier ne sont pas affiches sur telephone.

5. Sauvegarde automatique

Chaque modification est sauvegardee automatiquement dans IndexedDB, une base locale du navigateur. Cela conserve les tris, notes, dimensions et images importees sur le meme appareil et le meme navigateur.

Le message Sauvegardee automatiquement confirme que la session a ete ecrite. Le stockage est local : il n'est pas synchronise avec un autre telephone ou ordinateur.

Bon reflexe : utilisez aussi Sauver pour produire un fichier JSON durable.

6. Historique des sauvegardes

Le bouton Historique conserve les dix dernieres versions locales. Chaque ligne indique sa date et le nombre de cartes.

  1. Ouvrez Historique.
  2. Choisissez une version avec Restaurer.
  3. Confirmez le remplacement de la session actuelle.

Les versions sont propres au navigateur. Exportez un JSON si vous voulez les conserver ailleurs.

7. Dimensions et raccourcis

Le bouton Dimensions ouvre l'editeur. Vous pouvez modifier le nom, le type, les options, les couleurs, le caractere obligatoire et la touche associee.

Les raccourcis sont personnalisables sur une seule touche. Si deux dimensions ou options utilisent la meme touche, les champs sont signales en rouge et l'editeur refuse de se fermer tant que le conflit n'est pas corrige.

Sur ordinateur, les touches sont actives dans la vue detail. Par exemple, une touche de dimension peut faire passer ses reponses en cycle.

8. Import et export

Importer des images

Images permet d'ajouter des fichiers locaux. Les doublons sont ignores. Les images sont conservees dans IndexedDB pour la sauvegarde automatique.

Charger une session

Charger accepte un fichier JSON. Un JSON avec images integrees est autonome ; un JSON leger necessite de recharger les images correspondantes.

Sauver une session

Sauver demande si les images doivent etre incluses :

  • OK : JSON autonome, plus volumineux mais partageable.
  • Annuler : JSON leger, les images restent externes.
Le Card Sorter fonctionne dans un navigateur moderne, sans installation et sans backend.
